Управление сайтом

Админ-панельверсия 11

Правки сохраняются как черновик в этом браузере. Чтобы их увидели все посетители сайта, нажмите «Опубликовать на сайт» — данные и фото запишутся прямо в репозиторий GitHub.

Как включить публикацию (один раз)
  1. GitHub → Settings → Developer settings → Personal access tokens → Fine-grained tokens → Generate new token.
  2. Repository access: Only select repositories → выберите репозиторий сайта.
  3. Permissions → Repository permissions → Contents: Read and write.
  4. Скопируйте токен (начинается с github_pat_) и вставьте его при первой публикации. Он хранится только в вашем браузере. Админка открыта всем, но без токена опубликовать изменения нельзя.
