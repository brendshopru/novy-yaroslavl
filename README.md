# Новый Ярославль

Статический сайт агентства недвижимости.

## Файлы
- `index.html` — публичный сайт.
- `admin.html` — первая версия админ-панели.
- `data.js` — данные объектов, команды и отзывов.
- `app.js` — логика каталога и калькулятора.
- `styles.css` — стили.

## Важно про админку
Сейчас админка работает без backend: изменения сохраняются в `localStorage` текущего браузера. Кнопка «Экспорт data.js» создаёт обновлённый файл, который затем можно заменить в репозитории.

Для полноценной админки с авторизацией, загрузкой фотографий и общей базой данных следующим этапом нужно подключить backend (например, Supabase). Тогда изменения будут сразу доступны на сайте всем посетителям, без ручной замены `data.js`.

## GitHub Pages
Сайт можно разместить как статический проект. Админку не следует считать защищённой системой доступа до подключения backend/auth.
